This is a pre-built distribution of GNU binutils 2.47 and GDB for z80-none-elf.

Source: https://github.com/CE-Programming/binutils-gdb.git
Original Source: https://sourceware.org/git/binutils-gdb.git

This software is licensed under the GNU General Public License v3.
See the license directory for full license texts.

This distribution includes CEdev modifications for eZ80 call-frame information,
24-bit DWARF addresses, and GDB return-address stepping. The fork's
binutils-2_47-cedev branch preserves those changes as individual commits.

Source code is available at the URLs above. See source-info.txt for the exact
commit used to build this distribution and a link to its corresponding source.
